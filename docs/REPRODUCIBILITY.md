# Reproducibility

Use Python 3.12, CrewAI 1.15.44, Ollama and `qwen2.5:1.5b-instruct`. Install project dependencies and run pytest as shown in the README. `procurepilot.multisource_crew.run_multisource()` fetches three reviewed supplier product pages and runs the six sequential tasks. Fresh supplier prices, stock, HTML, LLM wording and runtime can change. The included trace `examples/verified_multisource_trace.json` records the 21 November 2026 observation. Unit tests use synthetic fixtures and do not require Ollama. No raw supplier HTML is bundled for replay. The Streamlit app stores runs in local SQLite, excluded from Git.
